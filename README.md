# 📒 Address Book Management System in C

## 📌 Overview

The **Address Book Management System** is a menu-driven application developed using C programming. It provides an efficient way to manage contact information by allowing users to add, search, edit, delete, and display contacts.

The project focuses on implementing core C programming concepts, structured programming, and input validation.

## ✨ Features

- **Add Contact:** Add new contacts with name, phone number, and email address.
- **Search Contact:** Search for contacts using their name, phone number, or email.
- **Edit Contact:** Modify existing contact information.
- **Delete Contact:** Remove unwanted contacts.
- **List Contacts:** Display all saved contacts.
- **Input Validation:** Validate phone numbers and email addresses.
- **Duplicate Prevention:** Prevent duplicate phone numbers and email addresses.

## 🛠️ Technologies Used

- C Programming
- Structures
- Arrays
- Functions
- Pointers
- String Handling
- Input Validation

## ⚙️ Validation Rules

- Phone number must contain exactly 10 digits.
- Phone number must start with digits 6–9.
- Duplicate phone numbers are not allowed.
- Email address must contain a valid `@` symbol and `.com` extension.
- Duplicate email addresses are not allowed.

## 💻 How to Compile and Run

**Step 1:** Clone the repository.

```bash
git clone <your-repository-url>
```

**Step 2:** Navigate to the project directory.

```bash
cd AddressBook-Project-in-C
```

**Step 3:** Compile the source files.

```bash
gcc *.c -o addressbook
```

**Step 4:** Run the application.

```bash
./addressbook
```
